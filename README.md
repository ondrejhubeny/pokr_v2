# Pivnice Pizza POKR — Verze 2 (Znojemská Poctivost)

Světlý, přívětivý bistro & pivnice editorial koncept v teplých přírodních tónech (krémová, pivovarská zelená, cihlová terakota). Zdůrazňuje čerstvou rekonstrukci, ocenění **Hvězda sládků**, přehlednou filtrovatelnou nabídku (pivo, pizza, burgery, řízky, fokáče), balíčky pro oslavy & catering a herní zázemí (kulečník, šipky, fotbálek).

- **Web / Projekt:** `pivnicepizzapokr.cz`
- **Nasazení:** Statický web připravený k okamžitému nasazení na Vercel.
